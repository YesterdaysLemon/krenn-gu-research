## Durable authority boundary

The clarified contract permits Codex to review, freeze, and execute a mapping
only when it is all of the following:

1. routine;
2. non-ambiguous;
3. evidence-backed; and
4. frozen as an exact old-path to new-path batch with the existing mapping
   hash and base-SHA controls.

The batch `approved_by` value must name Codex as the actual reviewer and state
the repository-owner standing-delegation basis.  The owner must not be named
as the exact-mapping reviewer unless the owner actually reviewed that mapping.

The delegation explicitly excludes:

- scientific status or scope decisions;
- genuinely ambiguous proof-boundary ownership; and
- architectural choices that require owner preference.

Those remain owner-gated.  Classifier confidence remains proposal evidence
only and is never approval or review authority.
