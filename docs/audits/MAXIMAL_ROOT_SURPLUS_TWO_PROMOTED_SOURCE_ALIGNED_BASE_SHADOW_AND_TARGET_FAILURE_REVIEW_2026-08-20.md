

`lambda=mu compose epsilon_A` annihilates the **complete** upstairs nuisance

only for selectors declared to have this factor-through form.


`N_C^base`.  If all base classes are swallowed, the nonzero `Pi_Q` lies in the
explicit Laplace nuisance sum; this is a circuit, not a contradiction.
