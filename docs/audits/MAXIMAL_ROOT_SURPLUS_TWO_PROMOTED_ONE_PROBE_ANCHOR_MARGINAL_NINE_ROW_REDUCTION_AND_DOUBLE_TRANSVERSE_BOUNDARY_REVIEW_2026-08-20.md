## Load-bearing construction

For one probe index `i` and the other index `j`, contraction at the actual
root vector gives

```text
rho_i:E_A^tr -> x_(a_j)^perp.
```

The codomain has dimension two.  It is exact because any covector
annihilating `x_(a_j)` can be tensored with a covector taking value one at
`x_(a_i)`.  If

```text
u_i=rho_i(omega)!=0,
```

then

```text
mu_i(v)=u_i wedge rho_i(v)
```

has one-dimensional image and kernel dimension seven.  Since
`mu_i(omega)=0`, it factors through the `GLS23` anchor quotient.  Applying it
to the exact labelled nuisance sum commutes with every port coefficient
slice and kills only the projected-zero `D=Q` term and the top-anchor line.
The root image has dimension one, so tensoring with `V_C^*` gives nine rows.

At `r=3`, the target response attached to complement `C` is the physical pair
response on `Uhat-C`, while the top target is the physical four-port response
on `Uhat`.  Six useful marginal rows plus one useful top row therefore give
exactly the seven same-graph responses assumed by `GLD3`; its activity gate is
still an additional hypothesis.

## Hostile assertions

   the other root is exactly the defining transverse scalar, hence zero.

2. **The contraction image might be a proper line.**  False.  Tensor a desired
   annihilator covector with any covector normalized at the contracted root.

3. **A root coordinate was inverted.**  False.  Surjectivity uses existence of
   a normalized covector in the proof; the physical quotient itself is the
   polynomial exterior map `u_i wedge rho_i(-)` and divides by nothing.

   `u_i wedge u_i=0`.

   core has the explicit rank-one/rank-two alternatives.
