## What changed

The starting advice was to keep full physical source equations and actual
shared cofactors, rather than infer weights from Boolean supports or keep
adding isolated support cuts. This run followed that direction.

- **Exact source implications:** a two-edge shore obstruction and an
  all-order two-slice shared-hafnian transfer retain actual source factors.
  A 129-entry Boolean support still avoids the tested template orbits; it
  is not a weighted witness. The tested degree-five and pure-attached
  degree-six module limitations are scoped to their declared spaces.
  See [the source-module checkpoint](source-module-resolution-attempt-2026-09-14.md).
- **A complete finite scaffold exclusion:** all 96 hollow crossing entries
  between two protected K4 components are excluded at n=8 using all source
  equations and a portable independently replayed RUP certificate. This
  excludes that scaffold family, not unrestricted n=8 witnesses.
  See [N8PS](../../claims/finite/n08/EIGHT_VERTEX_PROTECTED_SCAFFOLD_EXCLUSION.md).
- **An all-order limitation:** for every fixed minority depth r, some
  finite protected scaffold passes every full source test through r but
  fails an explicit global word. Order depends on r. Thus fixed-depth
  testing cannot uniformly exclude the scaffold.
  See [PSFD](../../claims/arbitrary-order/PROTECTED_SCAFFOLD_FIXED_MINORITY_DEPTH_NO_GO.md).
- **A reusable common-star contradiction:** S1 and both S2 families exclude
  every singleton port. If just one binary color-pair graph is a union of
  complete bicliques, a directed resource cycle constructs a nonzero mixed
  word. In particular, ports bounded by two in just one color pair are
  impossible under the full target.
  See [PSCS, especially (10)--(15)](../../claims/arbitrary-order/PROTECTED_SCAFFOLD_COMMON_STAR_COMPONENT_TARGET_OBSTRUCTION.md).
- **Both proposed supplies fail exactly:** S1 + both S2 + the entire
  physical four-minority system U4 force neither complete tripartite
  alignment nor even one complete binary decomposition. The first exact
  control has n=2880 and fails a global word by 2^(-360). The stronger
  control has n=24000; every binary connected component is noncomplete,
  while its remaining global failure is (-463/2592)^600.
  See [PSRA](../../claims/arbitrary-order/PROTECTED_SCAFFOLD_COMMON_STAR_RESOURCE_ALIGNMENT_NO_GO.md)
  and [PSBS](../../claims/arbitrary-order/PROTECTED_SCAFFOLD_COMMON_STAR_BINARY_SUPPLY_NO_GO.md).

## The key review target

These last controls use actual weights in Q(sqrt(3)), not support
abstractions. For PSBS, overlapping embedded invertible blocks produce
M with orthogonal relative inverse M Hadamard M^(-T) and noncomplete
support. A signed tensor triple, followed by a two-clone lift, preserves
all S1/S2 identities. A finite SL(2,F5) cover makes the physical gadgets
legal and all 423360 component triangles coherent. An exhaustive matching
classification then proves **all U4**, without enumerating those words.

Please challenge: the single tensor minus sign; same-color S2 as well as
distinct-color S2; deleted background spokes in the assembly bridge;
completeness of the four-minority classification; and scalar factorization
of the explicit global failure. The
[dedicated review](../audits/COMMON_STAR_BINARY_SUPPLY_REVIEW_2026-09-14.md)
pins the primary, fixture and two independent audit programs. Each program
runs with Python and supports an optional --output receipt path.

## Where the argument stops

The conditional resource consumer survives, but its proposed local supply
does not. The remaining [FB parent](common-star-q4-parent-attempt-2026-09-14.md)
retains every binary component assignment and the distinct-color S2 coupling.
It has no proof or counterexample from this run. A directed cycle with
q=-1 realizes the two-color target with singleton ports, so binary targets
alone are insufficient. An arbitrary-witness-to-scaffold reduction also
remains absent. No global resolution follows from these results.
