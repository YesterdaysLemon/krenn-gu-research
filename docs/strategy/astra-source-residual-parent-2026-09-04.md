by N8R2C has no H2 edge from either endpoint to an outsider. Therefore it
must be an isolated edge component of H2, or consist of two isolated H2
vertices. These are necessary conditions only: coordinate synchronization
of their rank-one exterior factors would still have to be proved.

Also, every edge in an invertible-edge component containing another edge
automatically has a zero-joint-kernel outsider: one endpoint has another
invertible incident block. Thus the N8R2K necessary boundary is automatic
on these edges, and exchanging along adjacent invertible edges merely
relocates the zero-kernel defect. An isolated invertible H2 edge instead
has only rank-at-most-one exterior legs, so zero joint kernels are
impossible; N8R2K would force a coordinate-axis port there.
