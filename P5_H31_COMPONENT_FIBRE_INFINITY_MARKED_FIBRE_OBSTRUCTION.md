# Complete marked-fibre obstruction on first-plane infinity

## Status

This is an exact characteristic-zero obstruction.

The first plane of the known pure rank-two component has a projective
line at infinity outside the finite five-parameter chart.  The earlier
theorem
[`P5_H31_COMPONENT_FIBER_INFINITY_OBSTRUCTION.md`](P5_H31_COMPONENT_FIBER_INFINITY_OBSTRUCTION.md)
excluded one canonical marked-row section of this divisor.

The complete marked-basis fibre is now excluded.  For every plane tuple
on this first-plane Schubert divisor, every kernel-row shift, every
distinguished source coordinate `q=0,1,2,3`, and every binary
`Delta_2` extension direction, a neighbouring one-marked map is
injective in a mode with a transverse pure coordinate.  Consequently
no point of this divisor lifts to `H31`.

The internal `E=0` divisor has since been closed separately.  This does
not close the second diagonal-quadric component, any further
pure-compression component, or the separate `H22` branch.

## Normalization and the full marking fibre

Use the boundary rows of the canonical theorem, with `H,N!=0`,
`(A,D)!=(0,0)`, and `E` arbitrary.  The source action

```text
diag(N,N,1,1/H)
```

and nonzero row rescalings send

```text
(A,D,E,H,N) -> (AH,D,E,1,1)
```

and act bijectively on the four row-shift coordinates by

```text
(t0,t1,t2,t3)
  -> (N t0/H, N t1, t2/N, t3/(HN)).
```

Thus write `H=N=1` and use canonical pure rows

```text
a0=(0,0,1,1),
a1=(0,0,1,1),
a2=(0,1,0,E),
a3=(1,0,1,0),
```

with kernel rows

```text
b0=(-D,A,0,D-AE),
b1=(E,1,-E,-E),
b2=(-1,0,1,0),
b3=(0,0,-1,1).
```

The pure restriction has only

```text
coefficient(a0 a1 a2 a3)=2.
```

The pure tensor fixes the kernel line `C b_i` in each row plane.
Up to row rescaling, every marking over the same four planes is
therefore

```text
a_i(t)=a_i+t_i b_i,        t in C^4.
```

## Absolute binary incidence

For distinguished coordinate `q`, append an eight-entry extension
vector `z` after deleting `q`.  Let `M_q(t)z=0` denote the fourteen
mixed binary coefficients, and let `d_A(z),d_B(z)` be the two diagonal
coefficients.  Saturate by

```text
(A,D)!=(0,0),        d_A(z)d_B(z)!=0,
```

and eliminate `z`.  Absolute elimination over `Q` has respectively
`4,3,6,8` minimal projection components:

```text
q=0:
 <D t0+1,t3-1,t1,E-t2,A>
 <t3,t2,t1,E-t2>
 <t1 t2-1,t3,t0,E-t2,-D t1+A>
 <t3,t2,t0,E-t2,D>

q=1:
 <2E t1-1,A t0-4t1,t3,t2,D>
 <2E t1-1,D t0+1,t3,t2,A>
 <t1 t2-1,t3,t0,E-t2,-D t1+A>

q=2:
 <t3,t2,t1,E>
 <t3,t1,E-t2,A>
 <AE t2+DE-Dt2,t3,t1,t0>
 <E^2 t1+t2,A t2+D,t3,t0>
 <t3,t2,t0,D>
 <D t0+1,t1,E-t2,A>

q=3:
 <t3-1,t1,E-t2,A>
 <t3,t2,t1,E>
 <t2,t1,t0,E>
 <AE t2+DE-Dt2,t3-1,t1,t0>
 <t3,t2,t1,t0>
 <t2,t1,t0,D>
 <E t1-1,A t2+D,t3,t0>
 <t3,t2,t0,D>.
```

These are projection closures.  Some closed subloci have no binary
extension with both diagonals nonzero; retaining the diagonal
saturation in the next step handles those closure artifacts exactly.

## Residual-cover obstruction

For mode `i`, let `p_i` be the distinguished column of the pure
one-marked map and let `N_i(z)` be the neighbouring one-marked map.
A ternary lift must satisfy

```text
(entry of p_i) * (every 4-minor of N_i(z))=0.
```

Rows of `N_i` are numbered `000,001,...,111` as `0,...,7`.  The
following small pools of `(mode; rows)` contain all certificates used:

| `q` | certificate pool |
| ---: | --- |
| 0 | `(1;0157)`, `(2;0467)`, `(3;0137)`, `(2;0237)`, `(0;0137)`, `(2;0267)` |
| 1 | `(0;0137)` |
| 2 | `(3;0157)`, `(1;0157)`, `(3;0147)`, `(1;0457)`, `(3;0137)`, `(0;0137)`, `(0;0157)`, `(2;0267)` |
| 3 | `(0;0267)`, `(3;0137)`, `(1;0157)`, `(3;0157)` |

The 21 projection components split into 25 rational charts.  On each
chart, write an arbitrary extension in an exact basis of `ker M_q`.
For every selected determinant `Delta`, form

```text
r = Delta/(d_A d_B).
```

The primary verifier reconstructs these rational functions.  It then
proves that the ideal generated by all nonzero products

```text
(entry of p_i) r
```

is the unit ideal after inverting `d_A`, `d_B`, and the chart
parameters.  This is an exact no-common-zero calculation over `Q`.
Across the atlas it checks 18 two-dimensional and 7
three-dimensional mixed kernels and 154 nonzero residual products.

The rational kernel charts have only the following exceptional
divisors:

```text
Et1=-1,   t3=-1,   Dt0=-1,   t3=0,   t2=E.
```

Each is either checked in a separate denominator-free kernel basis or
lies in an already listed component.  For the relation component,

```text
(AE t2+DE-Dt2)|_(E=t2)=A t2^2,
```

so its omitted divisor is exactly covered by the `A=0` or `E=t2=0`
components.  No finite-field inference is used here.

Therefore every binary extension with `d_A d_B!=0` has a selected mode
with `p_i!=0` and `rank N_i(z)=4`.  The third target row must vanish on
the neighbouring hyperplane because `N_i(z)` is injective, and on the
remaining pure coordinate because `p_i!=0`.  It vanishes globally,
contradicting target rank three.  This proves the theorem.
